# WiFiKill

玩机圈的老伙计们，应该都记得当年那个"一键断人网"的神器 —— WiFiKill 吧？

当年多少人的青春（和恶作剧），就是用它在一个局域网里"大杀四方"。后来原作者停更，APK 失效、崩溃、各种不兼容，这应用就慢慢沉了……

直到现在 —— 它回来了！

我花了不少时间，基于最新的技术栈把它从"能装但没法用"重新做成了"好用且能持续更新"的版本，核心依然是原汁原味的 ARP 断网那一套，但底子全换新了。

✨ 现在的功能：
🔍 自动扫描当前网络所有设备
⛔ 单设备 / 全选 一键阻断断网
✅ 全放行，恢复全网
📌 置顶常用设备
⭐ 白名单、设备备注
🏷 设备类型识别（厂商 / 移动设备）
🛡 防御模式，防 ARP 攻击
🌙 深色模式 + 中英文切换

⚠ 重要提醒：
工具仅供在自有或已授权网络下测试学习，需要授权ROOT，别拿去搞别人家的网，出了事后果自负 —— 玩归玩，别踩线。

凌晨一点，对床的室友还在"开黑"，键盘敲得跟发电报似的，嘴里还喊着"上上上""草"。
忍了十分钟，我打开 WiFiKill，轻轻点了他的设备——阻断。
五秒后："卧槽？我掉线了？网呢？？？"
他说了句"等我重连"，就再没声了。
LOL输了可以再打，觉睡不好是真难受。工具嘛，该出手时就出手。😏
